# Skill Basics Quiz

Test your understanding of the UAASP system.

## Questions

### 1. What file format does the open standard use?
a) README.md  
b) SKILL.md  
c) skill.txt  
d) config.json  

**Answer:** b) SKILL.md

---

### 2. What are the REQUIRED fields in SKILL.md frontmatter?
a) `name` only  
b) `description` only  
c) `name` and `description`  
d) `name`, `description`, and `license`  

**Answer:** c) `name` and `description`

---

### 3. Where do you put the skill description?
a) Body of SKILL.md  
b) YAML frontmatter `description` field  
c) Filename  
d) README.md  

**Answer:** b) YAML frontmatter `description` field

---

### 4. How do you share skills with your team?
a) Email  
b) Git repo  
c) Slack  
d) Print + fax  

**Answer:** b) Git repo

---

### 5. Which command initializes a new warehouse?
a) `uaa sync`  
b) `uaa init`  
c) `uaa status`  
d) `uaa list`  

**Answer:** b) `uaa init`

---

### 6. Which command syncs skills to all 4 tools?
a) `uaa sync --all`  
b) `uaa init`  
c) `uaa status`  
d) `uaa list`  

**Answer:** a) `uaa sync --all`

---

### 7. What does `uaa status` show?
a) Only skill count  
b) Skill count, tool dirs, last modified time  
c) Only tool directories  
d) Nothing  

**Answer:** b) Skill count, tool dirs, last modified time

---
